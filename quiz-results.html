온보딩 퀴즈가 낼 수 있는 결과는 16가지

퀴즈와 결과는 API 없이 정해진 규칙으로 돌아갑니다. 아래 16가지에 맞는 사진만 준비하면 모든 경우가 채워집니다.

Action items

해야 할 일

  1. 퀴즈 카드를 12장으로 둘지 16장으로 늘릴지 정하기16장이면 유형당 1장이라 사진 16장이 퀴즈와 결과에 함께 쓰입니다. 아래 "카드 수" 참고.
  2. 초안 상태인 유형 이름 12개 확정하기확정된 이름은 Quiet Classic, Easy Minimal, Workwear, Ivy 4개뿐입니다.
  3. 룩 사진 16장 구하기아래 표의 "사진 브리프"대로. 일반인 느낌, 옷이 잘 보이는 세로 사진. 유명인과 브랜드 로고는 제외.
  4. 카탈로그 상품 사진 불일치 고치기예: "Grey flannel trousers"에 정장 상의 사진이 나옵니다. 결과 화면의 아이템 타일과 풀착장 보드가 이 사진을 씁니다.
  5. 사진과 확정한 이름을 Pairly에 반영하기Lovable에 프롬프트로 넣거나, GitHub 연결 뒤 코드에서 직접 교체.
  6. 데모 주소(?demo=1)로 처음부터 끝까지 한 번 돌려 보기실제 손가락 스와이프, 직접 찍은 사진 업로드, Get feedback 포스팅은 아직 확인 전입니다.

카드 수: 두 가지 안

제안

16장, 유형당 1장

룩 사진 16장이 퀴즈 카드이자 각 유형의 대표 사진이 됩니다. 모든 축이 8 대 8로 균형이 맞습니다. 회의에서 말한 스와이프 10~20개 범위 안입니다.

대안

12장 유지

16장 중 City Minimal, Dapper, Gentle Heritage, Weekend Pop 4장을 빼면 축마다 6 대 6이 됩니다. 빠진 4개 유형은 결과용 사진만 따로 필요합니다.

필요한 사진

  • 룩 사진 16장. 일반인 느낌, 얼굴보다 옷이 잘 보이는 전신이나 상반신, 세로 비율.
  • 아이템 타일. 결과 화면의 "Pieces people like you wear"에 유형당 4개. 카탈로그 40개의 사진을 재사용하면 새로 구할 필요는 없습니다.
